# HAOQI.design 技术与交互分析

分析日期：2026-06-21

## 审计范围

- 页面：<https://haoqi.design/>
- 目标：识别实现技术、交互特点，并判断哪些机制适合迁移到张弦个人主页。
- 证据：当前访问页面截图、DOM 结构、公开静态资源、公开前端脚本，以及作者公开发布说明。

## 已确认的实现

- Next.js 16.1.6、React 19.2.4、Turbopack。
- Three.js r184 + React Three Fiber，全屏 Canvas 承载 3D 场景。
- Three.js 物理材质与自定义 Shader，包含玻璃/高光材质。
- React Three Postprocessing / EffectComposer，自定义点阵与径向遮罩转场。
- Lenis 平滑滚动；滚动位置、速度和方向被封装成全局状态供动画使用。
- GLTF/GLB 资产：`hello.gltf`、`cursor.glb`、`cnt.gltf`。
- 鼠标位置通过全局 Pointer Provider 映射成 0–1 坐标，驱动 Canvas 动画和 3D 光效。
- 亮/暗主题、背景音乐、实时天气、项目图片、贴纸图片和三套本地字体。
- `prefers-reduced-motion` 降级规则和 1024px 移动端分支。

## 性能策略

- Canvas 使用按需渲染 `frameloop="demand"`。
- DPR 限制在 1–2；关闭原生抗锯齿，依赖后处理控制视觉质量。
- 使用 `powerPreference: "high-performance"`。
- 路由重型资源带加载进度和遮罩转场。
- Canvas 设置为 `pointer-events: none`，真实链接与按钮仍由 DOM 层负责。

## 主要交互

1. 首屏 3D 玻璃字体和光照响应鼠标位置。
2. 3D 自定义光标与贴纸形成可探索感。
3. Lenis 提供缓动滚动，章节动画由滚动位置/速度驱动。
4. Work、Contact 使用页内定位；支持键盘 T/B 快速到顶部/底部。
5. Theme 和 Sound 是显式控制项；S 键可切换声音。
6. 页面/菜单切换使用径向孔洞 + 点阵 Shader，而不是普通淡入淡出。
7. 项目以可点击语义化 Article/Link 呈现，Canvas 主要负责氛围，不替代内容结构。

## 迁移建议

最适合张弦主页的是“轻量迁移”，不是整站复制：

- 首屏右侧增加鼠标响应的柔和光斑/景深，保留当前头像和个人定位。
- 项目卡片增加指针跟随高光、图片轻微倾斜与文字错层进入。
- Section 切换加入一次短促的点阵或光圈揭示。
- 保留 DOM 内容、按钮和现有转化路径；3D 只作为视觉增强。
- 暂不引入全站 3D 光标、背景音乐、实时天气和重型页面转场。

## 风险

- 全量 Three.js 会显著增加首屏脚本和 GPU 压力。
- 过强的 3D 与持续鼠标响应会削弱作品和数据的阅读优先级。
- 声音默认开启容易造成打扰。
- Canvas 动效必须提供 reduced-motion 和移动端静态降级。
- 公开天气请求中的前端密钥属于可复制凭据，不应照搬这种实现。

## 证据限制

- 已完成桌面首屏截图和静态资源/前端代码检查。
- 连续 WebGL 渲染使自动化的第二张滚动画面捕捉超时；滚动与项目区结构通过语义 DOM 和公开脚本确认。
- 未进行键盘全流程、屏幕阅读器和低性能移动设备实测，因此不构成完整 WCAG 或性能审计。
